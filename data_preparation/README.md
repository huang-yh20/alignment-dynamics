# Data preparation

See [docs/DATA.md](../docs/DATA.md) for upstream datasets, model inputs, preprocessing commands, seed conventions, and output paths.

The task directories contain the IMDb, BeaverTails, HEx-PHI response-diversity, and emergent-advice preprocessors. Experiment configurations specify the required `prompt`/`completion` JSON files. `manifest.json` records the processed-input checksums. Raw data and processed datasets are excluded from Git.
